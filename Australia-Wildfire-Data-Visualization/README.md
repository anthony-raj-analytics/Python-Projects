# 🔥 Australia Wildfire Data Visualization

A data visualization project analyzing historical wildfire activity across Australia (2005 onwards) using Python's data visualization ecosystem.

## 🎯 Overview

This project explores patterns in wildfire occurrence and intensity across Australian regions over time, using statistical and geographic visualizations to surface seasonal trends and high-risk areas.

## 📊 Visualizations

- Trend analysis of wildfire frequency and intensity over the years
- Seasonal and regional distribution charts
- Geographic mapping of wildfire activity using Folium
