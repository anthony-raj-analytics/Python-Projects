# 📊 Automobile Sales Data Visualization

A data visualization assignment analyzing automobile sales trends during recession periods using **Matplotlib**, **Seaborn**, and **Folium**.

## 🎯 Overview

This project explores how economic recessions affected automobile sales across different vehicle categories, using a range of static and geographic visualizations to uncover patterns and insights.

## 📊 Visualizations

- Line plots showing sales trends across recession periods (1980, 1981–82, 1991, 2000–01, 2007–09, 2020 COVID-19)
- Bar charts comparing average vehicle sales by type during recessions
- Effect of unemployment rate on sales across vehicle categories
- Choropleth map (Folium) showing regional sales impact during recession periods
