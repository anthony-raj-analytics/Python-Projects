# Python Projects

A collection of Python data analysis and visualization projects completed during my Data Analyst learning journey — covering data cleaning, exploratory data analysis, interactive dashboards, and visual storytelling.

---

## 📂 Projects

### 🚗 [Automobile Sales Dashboard](./Automobile-Sales-Dashboard)
**Tools:** Python · Dash · Plotly Express

Interactive web dashboard analyzing historical automobile sales trends and the impact of recession periods on vehicle sales. Includes dynamic dropdowns for yearly statistics and recession-period comparisons, with line, bar, and pie chart visualizations.

### 📊 [Automobile Sales Data Visualization](./Automobile-Sales-Data-Visualization)
**Tools:** Python · Pandas · Matplotlib · Seaborn · Folium

Data visualization assignment exploring automobile sales patterns during recession periods using statistical plots and a choropleth map to identify regional sales impact.

### 📈 [Tesla vs GameStop Stock Analysis](./Tesla-GameStop-Stock-Dashboard)
**Tools:** Python · yfinance · BeautifulSoup · Plotly

Extracted historical stock price data via the yfinance API and quarterly revenue data via web scraping, then built a dual-panel dashboard comparing share price against revenue trends for Tesla and GameStop.

### 🔥 [Australia Wildfire Data Visualization](./Australia-Wildfire-Data-Visualization)
**Tools:** Python · Pandas · Matplotlib · Seaborn · Folium

Analysis of historical wildfire activity across Australia (2005 onwards), visualizing seasonal and regional trends using multiple chart types and geographic mapping.
