# Automobile Sales Statistics Dashboard

An interactive dashboard built with **Plotly** and **Dash** to analyze historical automobile sales trends, with a focus on how sales were affected during recession periods.

## 📊 Overview

The dashboard provides two report views, selectable via a dropdown:

1. **Yearly Statistics**
   - Yearly automobile sales trend (line chart, 1980–2013)
   - Total monthly automobile sales for the selected year (line chart)
   - Average vehicles sold by vehicle type in the selected year (bar chart)
   - Total advertisement expenditure by vehicle type (pie chart)

2. **Recession Period Statistics**
   - Average automobile sales fluctuation during recession periods (line chart)
   - Average vehicles sold by vehicle type during recessions (bar chart)
   - Total advertising expenditure share by vehicle type during recessions (pie chart)
   - Effect of unemployment rate on vehicle type and sales (bar chart)

## 🛠️ Tech Stack

- Python 3.8
- Dash
- Plotly Express
- Pandas
